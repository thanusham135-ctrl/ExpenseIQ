# ExpenseIQ
### Personal Finance & Expense Management System

> **A production-ready, full-stack personal finance application** built with a clean layered architecture using **React, Vite, Tailwind CSS, Spring Boot 3, Spring Data JPA, Spring Security with JWT, and PostgreSQL**.

---

## 📌 Architecture Overview

ExpenseIQ follows a strict, decoupled, enterprise-grade layered architecture:

```
[React 18 + Vite Frontend]
       │ (REST APIs + JWT Bearer Auth)
       ▼
[Spring Boot 3 REST Controllers]
       │
       ▼
[Service Layer (Business Logic & Validations)]
       │
       ▼
[Spring Data JPA Repositories]
       │
       ▼
[Hibernate ORM / PostgreSQL Database]
```

### Layer Breakdown
- **Presentation Layer (Frontend)**: React 18, Vite, React Router 6, Tailwind CSS, Recharts, Lucide Icons, and Axios with dynamic request/response interceptors.
- **Controller Layer (REST API)**: Exposes clean RESTful endpoints, handles HTTP parameters, invokes DTO validation with `@Valid`, and delegates all operations to services.
- **Service Layer**: Handles core domain business rules, user data isolation, budget threshold analytics, date range calculations, and financial reporting.
- **Repository Layer**: Extends Spring Data `JpaRepository` and `JpaSpecificationExecutor` with parameterized JPQL aggregation queries.
- **Security & Identity Layer**: Stateless JWT authentication with `BCryptPasswordEncoder`, custom `UserDetailsService`, and `JwtAuthenticationFilter`.
- **Database (PostgreSQL)**: Normalized tables with foreign key constraints, unique composite keys, check constraints, and high-performance indexes.

## 🚀 Key Features

1. **Secure Authentication & Isolation**
   - User registration and login protected with BCrypt password hashing.
   - Stateless JWT tokens with user claims and automatic Axios injection.
   - Comprehensive data isolation: users can never access or modify another user's financial data.
   - Automatic seeding of 14 default Income & Expense categories upon user registration.

2. **Executive Financial Dashboard**
   - **Real-time Metric Cards**: Total Income, Total Expenses, Net Balance ($Balance = Income - Expenses$), Current Month Spending, and Daily Average Outflow.
   - **Cash Flow Analytics Chart**: 6-month historical trend comparison between Income and Expenses using Recharts.
   - **Expense Distribution Chart**: Interactive Donut chart displaying current month spending proportion across categories.
   - **Recent Transactions Feed**: Quick glance at the latest financial movements with immediate visual status tags.

3. **Transaction Management (Income & Expense CRUD)**
   - Record inflows (Salary, Freelance, Business, etc.) and outflows (Food, Transport, Bills, Shopping, etc.).
   - Multi-criteria filtering by Type, Category, and Date Range.
   - Full-text search matching descriptions and categories.
   - Support for multiple payment methods: `UPI`, `CASH`, `CARD`, `BANK_TRANSFER`, and `OTHER`.
   - In-app editing and safe deletion with confirmation modals.

4. **Monthly Category Budgeting**
   - Configure category-specific monthly spending caps (e.g., Food: ₹5,000, Transport: ₹1,500).
   - Real-time computation of Spent, Remaining balance, and Percentage used based on actual transactions.
   - Visual progress bar transitions: green ($<80\%$), amber ($80\% - 100\%$), and red with a prominent **"Budget exceeded"** alert badge ($>100\%$).

5. **Financial Reports & Statement Audit**
   - Select any month and year for deep-dive cash flow reporting.
   - Category-wise expense statement table with percentage allocation.
   - **One-Click CSV Export**: Download statement data directly generated by the backend API.

6. **Custom Category Management**
   - Ability to add custom user-defined income and expense categories.
   - Integrity protection: prevents deletion of categories currently referenced by active transactions or budgets.

## 🗄️ Database Schema Design

The application runs on a PostgreSQL database named `expenseiq`.

### 1. `users` Table
- `id` (BIGSERIAL PRIMARY KEY)
- `name` (VARCHAR(100) NOT NULL)
- `email` (VARCHAR(150) UNIQUE NOT NULL)
- `password` (VARCHAR(255) NOT NULL - BCrypt Hashed)
- `created_at` (TIMESTAMP WITH TIME ZONE)

### 2. `categories` Table
- `id` (BIGSERIAL PRIMARY KEY)
- `name` (VARCHAR(100) NOT NULL)
- `type` (VARCHAR(20) NOT NULL - `INCOME` or `EXPENSE`)
- `user_id` (BIGINT REFERENCES users(id) ON DELETE CASCADE)
- `CONSTRAINT uq_user_category UNIQUE (user_id, name, type)`

### 3. `transactions` Table
- `id` (BIGSERIAL PRIMARY KEY)
- `user_id` (BIGINT REFERENCES users(id) ON DELETE CASCADE)
- `category_id` (BIGINT REFERENCES categories(id) ON DELETE RESTRICT)
- `type` (VARCHAR(20) NOT NULL - `INCOME` or `EXPENSE`)
- `amount` (NUMERIC(12, 2) NOT NULL CHECK (amount > 0))
- `description` (VARCHAR(255))
- `payment_method` (VARCHAR(30) NOT NULL - `CASH`, `UPI`, `CARD`, `BANK_TRANSFER`, `OTHER`)
- `transaction_date` (DATE NOT NULL)
- `created_at`, `updated_at` (TIMESTAMP WITH TIME ZONE)

### 4. `budgets` Table
- `id` (BIGSERIAL PRIMARY KEY)
- `user_id` (BIGINT REFERENCES users(id) ON DELETE CASCADE)
- `category_id` (BIGINT REFERENCES categories(id) ON DELETE CASCADE)
- `amount` (NUMERIC(12, 2) NOT NULL CHECK (amount > 0))
- `month` (INT NOT NULL CHECK (month BETWEEN 1 AND 12))
- `year` (INT NOT NULL CHECK (year >= 2000))
- `created_at` (TIMESTAMP WITH TIME ZONE)
- `CONSTRAINT uq_user_budget_month_year UNIQUE (user_id, category_id, month, year)`

## ⚙️ Setup and Installation Instructions

### Prerequisites
- **Java Development Kit (JDK)**: Version 17, 21, or 25.
- **Node.js**: Version 18+ (tested with v24).
- **PostgreSQL**: Version 14+ running locally on port 5432.
- **Apache Maven**: Version 3.9+.

### 1. Database Setup
Log into your PostgreSQL instance and create the database:
```sql
CREATE DATABASE expenseiq;
```
*(Optional: Run the provided schema script in `database/schema.sql` to initialize schema and indexes).*

### 2. Backend Configuration & Startup
Navigate to the `backend/` directory:
```bash
cd backend
```
Review or edit `src/main/resources/application.properties` to ensure your database credentials match:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/expenseiq
spring.datasource.username=postgres
spring.datasource.password=Postgres123
```

Compile and package the application:
```bash
mvn clean package -DskipTests
```

Run the Spring Boot application:
```bash
java -jar target/expenseiq-backend-1.0.0.jar
```
The backend will start on **`http://localhost:8080`**.

### 3. Frontend Configuration & Startup
Navigate to the `frontend/` directory:
```bash
cd frontend
npm install
npm run dev
```
The frontend dev server will start on **`http://localhost:5173`**.
